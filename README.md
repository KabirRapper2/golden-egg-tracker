# Golden Egg Tracker

Professional gig tracking and progress dashboard for a focused interactive coder turning skill into money.

## Live App

Open `index.html` in any modern browser. No build step. No dependencies. All data stays in localStorage.

**GitHub Pages (optional):** Enable Pages on the `main` branch and set the root to `/`. Then visit:
`https://kabirrapper2.github.io/golden-egg-tracker/`

## Features

- **Dashboard** — Editable target & saved amounts, progress bar, total earned, still needed, quick stats
- **Add Gig** — Date, category, description, amount (HKD), hours, status, notes
- **Gig Log** — Clean table with status color coding and delete
- **Golden Paths** — Hard Path (big money) vs Small Path (volume)
- **Job Ideas Bank** — Realistic, startable gig ideas

## Categories

- Coding Gigs
- Website Handling (Small Path)
- Website Building (Hard Path)
- Math Tools / Worksheets
- School Help / Tutoring
- Health / Fitness
- My Own Business
- Other

## Philosophy

Two valid paths:
1. **Hard Path** — Full websites & custom tools (higher pay, fewer clients)
2. **Small Path** — Handling & maintaining sites (lower pay, many more opportunities)

Both grow the egg.
